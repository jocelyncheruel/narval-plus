# Installer Narval+ — Espace étudiant

## Installation dans Chrome

1. Cloner le dépôt GitHub, ou choisir **Code → Download ZIP** puis décompresser l’archive.
2. Ouvrir `chrome://extensions` dans Chrome.
3. Activer **Mode développeur** en haut à droite.
4. Cliquer sur **Charger l’extension non empaquetée**.
5. Sélectionner le dossier décompressé.
6. Se connecter normalement à `https://narval.univ-ubs.fr/`, puis actualiser la page.

Chrome conserve l’extension tant que le dossier n’est pas déplacé ou supprimé.

## Mise à jour

Lorsqu’une version plus récente est activée par l’équipe Narval+, l’extension la vérifie à chaque chargement de Narval et affiche automatiquement un bandeau. Cliquer sur **Télécharger la mise à jour** pour récupérer directement le ZIP du dépôt.

1. Remplacer les anciens fichiers par ceux de la nouvelle version, sans changer l’emplacement du dossier.
2. Ouvrir `chrome://extensions`.
3. Cliquer sur le bouton de rechargement de **Narval+ — Espace étudiant**.
4. Actualiser l’onglet Narval.

## Classement communautaire

La participation est désactivée par défaut. Elle s’active depuis l’onglet **Classement**.

Seules les moyennes agrégées correspondant à la formation, au parcours, au semestre ou à l’année et aux compétences sont envoyées. Le nom, le prénom, le numéro étudiant et les absences ne sont pas transmis.

## Utiliser plusieurs appareils

Dans **Classement → Mes appareils**, choisir **Ajouter un appareil** sur l'installation principale. Copier le code temporaire, valable cinq minutes et une seule fois. Sur la nouvelle installation, coller ce code dans **Associer cet appareil**. Les deux installations remplaceront ensuite la même contribution, sans compter deux étudiants. Un appareil perdu peut être révoqué séparément depuis la liste.

**Supprimer ma contribution** efface définitivement les résultats communautaires, l'identité anonyme et tous les appareils associés.

## Désinstallation

Ouvrir `chrome://extensions`, puis cliquer sur **Supprimer**. Pour retirer auparavant une contribution communautaire, utiliser **Classement → Supprimer ma contribution**.
